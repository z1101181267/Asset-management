# 数据库资产设备管理（DB Asset Management）

基于 React + Vite + Ant Design 5 的企业级数据库资产设备管理平台。

## 功能模块

1. **登录界面**：企业风、数据库主题背景（`public/bg-login.png`，AI 生成）。
   - 演示账号：管理员 `admin / admin123`，普通用户 `zhangsan / 123456`
2. **资产设备管理**
   - 列表字段：资产设备名称、IP 地址、环境类型、数据库类型、是否容器、数据库版本、负责人
   - 点击设备行 → 详情抽屉：服务器账号/密码、数据库账号/密码
   - 密码默认密文（••••••••）；普通用户点击眼睛图标 → 输入**管理员账号+密码**验证后才显示明文，关闭/收起后自动恢复密文
   - 支持「新增账号密码」（类型：服务器 / 数据库）
   - 新增资产设备：填写全部基础字段，服务器、数据库两栏均可点 **+** 新增多组账号密码；数据库版本选项随数据库类型联动
3. **数据库权限变更记录**
   - 需求单：申请人、申请要求、执行情况、操作（查看 / 执行 / 删除）
   - 完成 → 仅显示「查看、删除」；未完成 → 显示「执行、删除」
   - 新增需求：填申请人 + 申请要求，提交后自动跳转到需求单列表并高亮，状态=待处理
   - 点击执行：状态置为「处理中」（其他人员此时看到处理中）；执行窗口内「完成」→ 在需求下追加执行结果、状态=完成；「中止」→ 状态=中止
4. **配置管理**
   - 环境类型：正式、测试、开发（可增删）
   - 数据库类型：Oracle、MySQL、PostgreSQL、SqlServer、KingBase、Mongodb（可增删，新增类型默认「所有版本」）
   - 数据库版本：Oracle 11.2.0.4 / 12.1.0.1 / 12.2.0.1 / 19–26 逐个；MySQL 5.7–9.0 逐个；SqlServer 2005–2026 逐个；KingBase、Mongodb、PostgreSQL 为「所有版本」，支持继续追加版本
   - 执行情况状态：待处理、处理中、中止、完成
   - 资产表单中「数据库类型 ↔ 数据库版本」联动取自此处配置

## 数据存储

前端本地存储（localStorage key：`db-asset-app-data`），支持多标签页实时同步；登录会话存 sessionStorage。接入真实后端时替换 `src/store.js` 的持久化层即可。

## 运行

```bash
npm install
npm run dev      # 开发：http://localhost:5173
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
```
